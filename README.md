# OWASP Top 10 Lab

A web application security portfolio repository structured around authorized testing, evidence collection, risk communication, and remediation validation for common application security weaknesses.

## Scope

This lab is designed for intentionally vulnerable training applications and local test environments only. It focuses on identifying weaknesses, explaining impact, and documenting fixes rather than targeting real systems.

## Coverage areas

- Broken access control
- Cryptographic failures
- Injection
- Insecure design
- Security misconfiguration
- Vulnerable and outdated components
- Identification and authentication failures
- Software and data integrity failures
- Security logging and monitoring failures
- Server-side request forgery

## Repository structure

- `docs/test-methodology.md` — structured assessment workflow
- `templates/finding-template.md` — professional vulnerability finding format
- `templates/remediation-validation.md` — retest evidence template

## Testing principles

1. Confirm explicit authorization and scope.
2. Prefer the least intrusive validation method.
3. Capture reproducible evidence without exposing secrets.
4. Separate technical severity from business impact.
5. Provide actionable remediation and validate fixes.

## Skills demonstrated
Web application penetration testing, Burp Suite workflow, OWASP methodology, vulnerability triage, secure design review, remediation validation, and security reporting.
